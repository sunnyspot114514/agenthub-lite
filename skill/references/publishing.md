# 发布门槛

此 Starter 默认**只在本地生成**。人工审核源 Markdown 和 `docs/` 中的所有公开文件后，用户选择：

A. Cloudflare Pages 直接上传：见 `CLOUDFLARE-QUICKSTART.md`。
B. GitHub 自动部署：见 `GITHUB-PUBLISH.md`。
C. 已授权 Wrangler CLI：用户先用浏览器完成 `npx wrangler login`，可经用户确认后让 Agent 发布 `docs/`。

**不可从「帮我建站」推断已同意公开发布**，更不可从「你觉得应该上传 GitHub 吗？」推断已同意创建公开仓库或 push。

凡是公开 Pages URL，里面的内容都应当是用户本来就愿意全世界看到的资料。不要承诺实时同步或国内长期可达。
