# 中山大学 15 分钟展示：AgentHub Lite

- 前 3 分钟：个人从 2022 年使用 ChatGPT 到 2026 年自己研究/开发 Agent 的故事。
- 3–5 分钟：痛点：每个新 AI 都要重新认识同一个人、同一份项目状态。
- 5–10 分钟：打开 Cloudflare Pages 公共示例，把相同 URL 给两个新开的不同 AI 会话，看它们分别提取项目/状态/下一步；展示已有四款国内模型的读取截图。
- 10–12 分钟：用 Skill/免安装提示词快速生成一个虚构学生示例；强调人工审核，非实时同步。
- 12–15 分钟：扫码下载 GitHub 教程/Skill；展示一张简单的入门路径，分享用户对独立学习和项目驱动研究的体会。

**演讲备用方案：**提前录屏与截图；现场不开启要求学生公开自己的隐私数据的互动。若校园网或 Agent 网页工具不可用，就用已录制的读取结果或复制 `context.txt`。

**二维码：** 仓库地址须实际创建后再放，不要凭空填写。站点地址可放用户已验证可访问的 Cloudflare Pages 项目 URL，提醒网络可能波动。
